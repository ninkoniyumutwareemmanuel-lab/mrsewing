# R55 — Owner-approved full-screen Terms popup (staging only)
Date: 21 November 2026. Owner approved the in-chat mobile popup visual, then authorised implementation.

## Narrow scope
Replaces the ineffective inline browser PDF <object> (which displayed a white error box in the owner's Android screenshot) with a full-viewport document modal. There is no visible website brochure text above or under the document. Opening /terms-and-conditions/ renders the dialog immediately; close returns to the previous same-origin page or Home. All five pages scroll vertically. Zoom controls, page count and download icon are included. On phones that lack native PDF embedding, real server-side rasterizations of the *actual approved PDF* are displayed as ordinary images; no third-party runtime renderer, new CMS, or external browser CDN is used.
